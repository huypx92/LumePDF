## LumePDF 1.1.1 — Page navigation improvements

- Enter a page number in the toolbar or thumbnail sidebar to jump directly to that page.
- Improved synchronization between the selected page, scrolling and zoom, including short slides at the top and bottom of a document.
- Show page count, file size, page dimensions in millimeters and standard paper size where recognized.
- Additional interface labels for all eight supported languages.
- Includes interactive PDF links, recent documents and update notifications.

### Tiếng Việt

- Điền số trang trên thanh công cụ hoặc cột thumbnail để chuyển ngay tới trang cần xem.
- Cải thiện đồng bộ số trang khi cuộn, phóng to và thu nhỏ, kể cả các slide ngắn ở đầu hoặc cuối tài liệu.
- Hiển thị tổng số trang, dung lượng, kích thước trang theo mm và khổ giấy tiêu chuẩn khi nhận diện được.
- Bổ sung nhãn giao diện cho tám ngôn ngữ. Có liên kết PDF tương tác, tài liệu gần đây và thông báo cập nhật.

### Download

The ZIP includes Windows x64 and x86 installers and the macOS source package for Apple Silicon and Intel. Close LumePDF before upgrading and use the same Windows architecture as your current installation. macOS compiles from source and requires Internet access and Xcode Command Line Tools. macOS source checks cover both architectures. Installation and use on a Mac have not been tested for this release.
