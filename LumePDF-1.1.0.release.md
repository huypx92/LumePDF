## LumePDF 1.1.0 — Interactive PDFs

- Click supported buttons and links in PDFs to jump to a page, open a website, or open a linked PDF in the same folder or a subfolder.
- Use Back and Forward to revisit pages after following an internal link.
- Reopen recently viewed PDFs from the toolbar or welcome screen.
- LumePDF continues to check for newer releases at startup and from **About → Check for updates**.

### Tiếng Việt

- Bấm nút và liên kết trong PDF để chuyển trang, mở trang web hoặc mở tệp PDF liên kết trong cùng thư mục hay thư mục con.
- Dùng nút Quay lại và Tiến tới để trở về các trang vừa xem.
- Mở lại tài liệu từ mục Gần đây. LumePDF vẫn tự kiểm tra phiên bản mới khi khởi động.

### Downloads

The ZIP includes Windows 64-bit and 32-bit installers and a macOS package for Apple Silicon and Intel. macOS builds from source and requires Internet access and Xcode Command Line Tools. The macOS source was checked for both architectures. Installation and interactive navigation have not been tested on a Mac.
