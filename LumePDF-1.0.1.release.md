## New in LumePDF 1.0.1

LumePDF checks GitHub for a newer stable version in the background at startup. If an update is available, the notification opens the official GitHub download page. You can also check manually from **About → Check for updates**. If you already use 1.0.0, download and install 1.0.1 once to get these notifications.

### Downloads

**LumePDF-1.0.1.zip** includes Windows x64 and x86 installers, the macOS source package for Apple Silicon and Intel, and a bilingual start guide. macOS builds from source on the first installation and needs Internet access and Xcode Command Line Tools. The macOS bundle was not run on a Mac during release preparation.

### Tiếng Việt

LumePDF sẽ tự kiểm tra khi mở và báo khi có bản mới. Bạn cũng có thể chọn **Thông tin → Kiểm tra cập nhật**. Nếu đang dùng 1.0.0, hãy tải và cài 1.0.1 một lần để nhận thông báo các bản sau.
