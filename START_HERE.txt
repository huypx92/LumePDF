ENGLISH
LumePDF is a desktop PDF viewer with PDFium rendering, a cover gallery,
page thumbnails, zoom, view rotation, color picking and JPG/PNG page export.
The interface includes Vietnamese, English, Chinese, Japanese, Korean,
French, Spanish and Russian.

WINDOWS
1. Extract the ZIP completely.
2. Open the window folder.
3. Most current Windows 10/11 PCs: use LumePDF_Setup_64bit_x64.exe.
4. For 32-bit Windows: use LumePDF_Setup_32bit_x86.exe.
5. Follow the installer and read HUONG_DAN_CAI_DAT_WINDOWS.txt.

MACOS — FIRST INSTALLATION BUILDS FROM SOURCE
1. Extract the ZIP completely and open the Mac folder.
2. This package contains source code and PDFium libraries for Apple Silicon
   and Intel. It does not contain a prebuilt native LumePDF executable.
3. Install Apple's Xcode Command Line Tools if they are not already available.
4. Internet access is required for the first build. The supplied installation
   script installs Rust with rustup if Cargo is missing and downloads the
   dependencies required to compile LumePDF.
5. Read Mac/HUONG_DAN_CAI_DAT_MAC.txt and Install_LumePDF_Mac.command before
   running the installer. It builds for the current Mac and installs into
   /Applications/LumePDF.app, replacing a previous copy at that location.
6. The supplied script also clears extended attributes from the installed app.
   Only run it if you trust this package. No macOS runtime test was performed
   as part of preparing this release.

NOTES
CMYK preview is an approximation for visual inspection. Actual printed color
depends on printer, paper, ink and profiles. LumePDF is a viewer; PDF text
editing, OCR, merging and digital signing are not advertised in this release.
