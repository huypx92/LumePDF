## LumePDF 1.1.2 — PDF drawing tools

- Press **D** to open the drawing toolbar. Add freehand strokes, lines, ellipses, rectangles and text as visual annotations while viewing a PDF. Use the eraser or undo to correct marks. Annotations are held in the current tab.
- On Windows, opening another PDF from File Explorer sends it to the running LumePDF window as a tab.
- Interactive PDF links, page navigation and update notifications are included.

### Tiếng Việt

- Nhấn **D** để mở thanh công cụ vẽ. Khi xem PDF, bạn có thể vẽ nét tự do, đường thẳng, hình elip, hình chữ nhật và thêm chữ, rồi dùng tẩy hoặc hoàn tác để sửa. Chú thích được giữ trong tab đang mở.
- Trên Windows, mở PDF khác từ File Explorer sẽ đưa tài liệu vào một tab trong cửa sổ LumePDF đang chạy.
- Có liên kết PDF tương tác, chuyển nhanh đến số trang và thông báo cập nhật.
